✨ FITUR YANG DIIMPLEMENTASIKAN:

  ✅ File Change Detection
     • CREATED - file baru dibuat
     • MODIFIED - content berubah
     • DELETED - file dihapus
     • UNCHANGED - tidak ada perubahan

  ✅ File Status Detection
     • READABLE - text file yang bisa dibaca
     • BINARY - file binary (PNG, JPG, etc)
     • NOT_FOUND - file tidak ada
     • TOO_LARGE - file > 10MB (safety limit)
     • UNREADABLE - permission/encoding error

  ✅ Snapshot & Comparison System
     • capture_snapshot() - capture file state
     • compare_snapshots() - bandingkan before/after
     • Thread-safe dengan locking mechanism

  ✅ Unified Diff Generation
     • RFC 3881 compliant format
     • Auto-truncation untuk diffs > 50K lines
     • Structured line-by-line parsing

  ✅ Hash-Based Detection
     • SHA256 hashing untuk exact comparison
     • Deteksi file yang di-restore user
     • Forensic capability untuk debugging

  ✅ Metadata Tracking
     • lines_added, lines_removed, lines_modified
     • file_hash_before, file_hash_after
     • file_mtime_before, file_mtime_after
     • Structured diff_lines untuk rendering

  ✅ Security & Safety
     • Path traversal protection
     • Binary file handling
     • Large file handling
     • Encoding fallback (UTF-8 → Latin-1)
     • Thread-safe concurrent access
